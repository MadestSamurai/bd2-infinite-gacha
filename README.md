# BD2 无限抽抽乐助手

[English](README.en.md) | 简体中文

适用于棕色尘埃2 Windows PC 客户端的独立无限抽抽乐助手。读取当前可抽服装与账号破度，按 A／B 目标和停止条件自动刷新、跳过动画；命中后保留结果，由你在游戏里确认。

[下载最新版本](https://github.com/MadestSamurai/bd2-infinite-gacha/releases/latest)

## 选择版本

两个版本都内置 **简体中文／English** 切换，不需要分别下载语言包。

| 版本 | 包含 .NET | 需要额外安装 | 建议 |
| --- | --- | --- | --- |
| **Portable** | 是 | 无 | 大多数用户选择这个 |
| **Lite** | 否 | .NET 8 Windows Desktop Runtime **x64** | 已装运行时，想下载更小的版本 |

下载 EXE 即可双击运行；ZIP 另外包含中英说明和许可证。Release 附 `SHA256SUMS.txt`，可以用 PowerShell `Get-FileHash 文件.exe -Algorithm SHA256` 核验。

## 使用

1. 启动并登录游戏，进入无限抽抽乐，手动抽出第一次十连，停在结果页。
2. 打开助手，点「连接游戏」。升级过组件或本次游戏已连接其他工具时，请先正常重启游戏。
3. 点「未满服装 → B」，将未拥有及 +0～+4 的可抽服装加入左侧 B 列表。
4. 在 B 中选中优先目标，点「移入 A →」。Ctrl／Shift 可以多选；双击或 Enter 互移，Delete 移出分组。其他服装通过「添加服装…」选择。
5. 填写顶部 A 阈值，以及需要的低档位条件；点「开始刷新」。达标自动停止，最终保留／购买仍由你在游戏内决定。

右上角可即时切换语言；切换不会重启任务或改变分组。服装、角色和卡池名称使用**游戏当前语言**。

卡池下拉框以**截止时间**区分活动，按新到旧排列；时间采用电脑本地时区，悬停可查看时区和游戏活动名。「当前结果」标记游戏正在显示的卡池。同一时间以卡池编号区分，游戏未提供日期的历史卡池排在末尾。调整排序不改变已有分组或停止条件。

## 停止条件

A 是优先目标，B 是补充目标，同一服装只能属于一组。顶部填写「A 至少 N 个」，范围 1～10；下方自动生成 N−1……0，各行可单独启用。

例如顶部填 3，再启用以下条件：

| 实际 A 数量 | 停止要求 |
| --- | --- |
| ≥ 3 | 无条件停止 |
| = 2 | B ≥ 3 |
| = 1 | B ≥ 5 |
| = 0 | 禁用，继续刷新 |

任何一条启用条件成立即可停止。低档位按 **A 数量相等**判断；A+B 不能大于10。非法或未完成输入会提示，但不会被重置。改变顶部阈值也保留隐藏档位的原输入。

- **重复服装按张数累计**：默认开启，同款每张分别计数；取消则按不同服装 ID 计数。
- **溢出服装不计**：按张数模式下默认开启，只计算升到 +5 所需张数。未拥有最多6张，+0最多5张，+4最多1张，+5不计。可单独取消。
- **刷新间隔**：默认1000ms，可调100～60000ms。上一次完整结果判定后才允许下一次；网络和游戏演出可能使实际间隔更长。
- 分组、条件按账号和卡池分别保存。停止或重开助手后不会自动开始刷新。

## 短暂中断与诊断

短暂读不到状态或界面时，最多等待15秒恢复；短暂文件占用会重试，保留当前任务。游戏弹窗关闭后自动继续。动画跳过使用游戏原生入口。

账号／进程／卡池变化、锁定结果和明确服务端错误仍会停止。服务器30秒未响应时不会盲目重发，避免跳过一份可能已经生成的结果。停止或关闭助手后不再发起新抽取，已发出的请求可正常返回。

本地数据位于 `%LOCALAPPDATA%\BD2InfiniteGacha\`：

| 文件 | 用途 |
| --- | --- |
| `settings.json` | 各账号、卡池的目标和条件 |
| `language.json` | 界面语言 |
| `desktop-events.jsonl`／`runtime-events.jsonl` | 恢复、停止和错误原因；自动限制体积 |
| `snapshot.json` | 最近库存、结果与动画状态 |
| `connection.json`／`compatibility.json`／`runtime.json` | 组件连接诊断 |

报告问题时提供工具版本、可见提示和事件日志相关几行即可。不要公开整份库存、账号数据或其他个人文件。

## 编译与贡献

Windows x64、.NET 8 SDK。普通编译和回归**不需要安装游戏**：

```powershell
.\build.ps1 -Locked
.\package.ps1 -Locked
```

产物在 `dist/v0.2.2/`。更多内容：[开发与兼容](docs/DEVELOPMENT.md) · [翻译维护](docs/LOCALIZATION.md) · [版本说明](docs/RELEASE_NOTES.md)。

工具连接时解析本机客户端接口，不附带游戏 DLL、游戏数据表、账号库或回放。发生无法可靠匹配的接口变更时会报告不兼容。
